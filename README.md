GAU CONNECT — PRO OFFLINE VERSION
=================================
Features:
- Python standard-library backend (no pip install required)
- SQLite database: gauconnect.db
- Farmer registration
- Farmer photo upload
- Cow/water survey
- Survey photo upload
- Admin dashboard
- Search farmers
- Delete records
- Live statistics
- Data persists after closing the browser/server
- English/Marathi/Hindi selector included
- No cloud database, CDN, Netlify, or external API required

RUN:
1. Open CMD in this folder.
2. Run: python server.py
3. Open: http://localhost:8000
4. Keep CMD open while using the website.
